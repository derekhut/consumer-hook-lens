## 这一屏上说话的东西有三个，各管一件事

改文案前先看清楚是哪一句，别串了：

| 位置 | 谁在说 | 说什么 |
|---|---|---|
| 顶部 `.bar` | 进度 | 外层「示例 1 / 3」，内层总量「这张图里有 2 处」 |
| 按钮下面那行小字 `holdHint` | 邀请动作 | 「按住下面，把刚才那几处拿掉」 |
| **压在图上那条横幅** `holdBanner` | **点破差异** | 「刚才先跳出来的是「限时倒计时」和「划线价锚定」」 |

第三条是这个演示真正要留下的东西 —— 它给差异**起了名字**。前两条都不能替它说话；
`tests/check-hold.js` 里有一条断言专门守着「邀请语和点破语不是同一句」。

## 怎么跑起来

1. 打开**微信开发者工具** → 「导入项目」
2. **目录**选这个文件夹
3. **AppID**：看 `project.config.json` 的 `appid` 字段
   - `touristappid` = 游客模式占位。界面功能都能跑，但**不能用云开发、不能上传发布**
   - `wx` 开头的一串 = 真正的小程序 AppID
     > clone 别人的仓库时，这一串不属于你，导入会直接报错 —— 改成自己的，或改成上一行的占位值走游客模式
   > 这里**故意不写具体值**。它是会变的，写进文档就会漂 —— 本仓库里真的发生过：
   > 文档还写着占位值，配置里的值却已经被换成别的一串，没人注意到。
   > `tests/check-docs.js` 里有断言守着「文档不许复述当前 appid」。
4. 后端服务：现在选「不使用云服务」，**阶段 7** 接云开发时再改成「微信云开发」

## 怎么跑测试

```
node tests/run-all.js
```

**判断标准：每一行末尾都显示 `0 失败`。** 不要去数一共有多少项 —— 每加一个文件总数就会变。

> 汇总脚本会自动发现 `tests/check-*.js`。**不要往 `run-all.js` 里硬编码文件清单** ——
> 有人加了套件却忘了加进清单，汇总会显示全绿而那个套件根本没跑。

## 目录结构

```

pages/card/        分享卡片：画布渲染 + 转发 + 存相册
data/shots.js      三段示例的**位置**（坐标），文案不写在这里

utils/reveal.js    揭示流程的纯逻辑（下一个未揭示的、进度文案、提示语）
utils/hold.js      「按住，只看商品」的纯逻辑（盖哪几处、点破差异那句话）
utils/card.js      卡片的**排版**：产出绘制计划，不碰 canvas
utils/canvas-draw.js  把绘制计划画到 canvas 上（页面和离线预览共用这一份）
utils/annotations.js  归一化矩形校验（0–1 坐标、越界裁剪、转百分比样式）

tools/             开发工具（不参与小程序运行）
cloudfunctions/    云函数（阶段 7 接入）
```

### 不开微信开发者工具也能看卡片

```
node tools/preview-card.js          # 三段示例各出一张，堆在一个页面上
node tools/preview-card.js 0 A1,B1  # 只出第一张示例、只标这两处
```

产出两个文件（都在 .gitignore 里，随时重新生成）：

- `tools/preview-card.html` —— **内联了 `utils/canvas-draw.js` 的源码**，用的是和小程序页面
  同一份绘制代码。改完排版跑一次就能看结果，不用开开发者工具、不用等编译。
- `tools/preview-card-N.svg` —— 同一份 plan 出的矢量图，不开浏览器也能看。

> 关键在那个「同一份」：如果预览工具自己再实现一遍渲染，它验的就不是真机上的那份代码，
> 「预览好看、真机画歪」就白验了。所以渲染代码被单独抽成了 `utils/canvas-draw.js`。

### 一条容易搞混的分界

- **改文案** → 改 `utils/hooks.js`（陷阱名、机制句、维度的收尾话都在那）
- **改位置** → 改 `data/shots.js`（每处的归一化坐标）
- **改产品名** → 改 `utils/brand.js` + `app.json`，**只有这两处**（见下）

示例数据里不写文案，就是为了避免同一句话存在两个地方。

### 产品名只允许出现在两个地方

`utils/brand.js` 是 JS 侧的唯一来源；`app.json` 是纯 JSON，import 不进来，只能硬编码 ——
**这是全项目唯一允许重复的地方**。`tests/check-brand.js` 会把整个项目扫一遍，
只要第三处又写了这个名字就会变红。

> 这个检查第一次跑就抓到两处真泄漏：`pages/journey/index.json` 自己盖了一层标题（已删，
> 改用 app.json 的全局标题），以及检查文件自己的注释里写了字面量。
> 注册时小程序名称就已经定下，而**小程序名称全平台唯一** —— 所以 `utils/brand.js` 里的名字
> **必须和注册名一个字都不差**。差一个字，微信里显示的是注册名、卡片和标题里写的是另一个，
> 演示的时候会被看出来。
> `check-brand.js` 守的是「不许出现第三处」，它守不了「和注册名一致」—— 这一条只能靠人核对一次。

### 测试怎么分层

| 层 | 测什么 | 例子 |
|---|---|---|
| 纯逻辑 | 不碰界面、只吃参数吐结果的部分 | `check-hooks`、`check-reveal`、`check-annotations`、`check-hold` |
| 排版 | 卡片的几何：折行、出界、压字、编号对不上 | `check-card` |
| 数据 | 示例本身是否自洽（坐标合法、id 在词典里、热区不重叠） | `check-shots` |
| 配置 | 产品名有没有漏改 | `check-brand` |
| 文档 | PRD 里的词典表有没有和代码漂开；文档提到的文件是否还在 | `check-docs` |
| 页面 | **页面状态机 + 画布渲染**。把 `Page`/`wx` 桩掉在 Node 里跑页面 | `check-page`、`check-page-card` |

最后两层是「有界面的手点」的补充，不是替代：手点能看出「框的位置对不对」，
看不出「连按 10 次之后哪个字段没还原」。两件事都要做。

### 为什么连文档都要检查

同一件事写两遍，就一定会有一遍忘了改 —— 这不是判断，是已经发生的事：

- PRD 第 6 节的词典表，在写完**一天之内**就漂了三处（C 维度的名字、D1 的机制句、E2 的名字）。
- 套件从 `check-page-hold.js` 改名成 `check-page.js` 之后，TODO 里有两处引用没跟着改。

两处都不是靠人看出来的，是脚本把全项目扫一遍才发现的。所以 `check-docs` 会：
逐条核对词典表的 id / 名字 / 机制句 / 收尾话，并检查文档里提到的每个文件是否真的存在。

## 这个项目的硬规矩

1. **一份内容只有一个来源。** 陷阱词典只在 `utils/hooks.js` 里写一遍，示例数据、卡片文案、云函数 prompt 全部读它。
2. **有界面的手点，没界面的必须写脚本。** 云函数、文案生成、矩形校验这类看不见的东西，「我点了一遍没问题」不算验证。
3. **错误不许吞掉。** 不做 `try { ... } catch (e) { /* 空 */ }`。要映射成用户能行动的提示，原始错误进日志，界面上有独立的失败状态 —— 不要用「加载中」一直转圈掩盖失败。
4. **优先用小程序自带组件**，不引第三方 UI 库（Vant / TDesign / uView）。`app.json` 里的 `"style": "v2"` 是官方设计规范，别急着覆盖。

### 文案规矩

**每条解读必须回答「它怎么起作用」，不能回答「它多坏」。**

- ✅「用更高的划线价作参照，让当前价格显得更划算」
- ❌「商家套路太深了，别上当」

`tests/check-hooks.js` 里有一条断言在自动守这条规矩（出现「不要」「套路」「警惕」这类词就会变红）。

## 坐标约定

所有标注矩形都是**相对整张图的 0–1 归一化比例**（左上原点），不是像素。
这是跨屏幕尺寸不错位的唯一办法 —— 换机型、换缩放，框都还在同一个元素上。

**写进内联样式的百分比字符串必须是干净的。** 教训：`0.544` 乘 100 会算出 `54.400000000000006`，
于是样式里出现 `top:54.400000000000006%`。原因是**先取整到 4 位小数、再乘 100**，浮点误差又回来了。
正确做法是**先乘 100、再取整到两位**。`tests/check-annotations.js` 会把 0 到 1 逐千分位扫一遍。

**坐标不要"看着差不多"填。** 用 `sips` 按估算值裁出那一块、自己看一眼，再改。本项目 6 处坐标
全部是这样核出来的 —— 其中 `B1` 第一次就量错了（右边界切掉了最后一个「9」），是裁图才看出来的。
